# ORACLIME Full Company Website

This is a complete responsive public-company website starter with:
- Home
- About Us
- Contact Us
- Login
- Partner / Technician / Super Admin role messaging
- Contact form validation
- Mobile responsive UI
- ORACLIME branding and AC/Air Conditioner terminology

## Important
The login and contact form are currently frontend demo functionality. For production, connect:
- Supabase Auth
- Supabase PostgreSQL
- Supabase Storage
- Backend/API validation
- RLS
- Real email/contact-form delivery

The detailed production platform requirements are in the ORACLIME Master Build Prompt.

## Run
Open `index.html` in a browser, or serve the folder with any static web server.

For the full production application, migrate this UI into Next.js + TypeScript + Tailwind + Supabase + Vercel and implement the real role-based workflows.
